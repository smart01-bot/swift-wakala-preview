# Swift Wakala — Minimal Interactive Preview

The public homepage is a full-viewport interactive browser rendition of Swift Wakala. No phone frames, alternate-theme mockups, external hero, marketing copy, walkthrough text, or surrounding control panel.

It opens on the Swift wing splash, goes to a role-selection screen, then the sample agent or main-agent workspace. Registration, requests, history, review and approvals remain interactive; visitors can switch dark and light inside the app.

The interface is derived from the frontend Development branch: the true Swift wing SVG, silver/AMOLED theme tokens, native-style agent home banner, transfer activity, latest request, and main-agent overview. This is still a **browser recreation**, not a native Expo app or actual authenticated implementation. All records are synthetic; no wallet transfers, backends, identity verification, or live settlements occur.

Entry: index.html -> styles.css, mobile.css, experience.css, minimal.css, model.js, app.js.
